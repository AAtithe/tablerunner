Set up Table Runner

This install has no admin yet. The setup code is in the Vercel logs: open the tablerunner project in Vercel, choose Logs, and search for "setup code". You become the first admin; everyone else gets their own sign-in on the Users screen.

    Postmark sending
    How to set this up in Postmark
    1. In Postmark, open Sender Signatures and verify the From address, or better the whole domain (add the DKIM and Return-Path records it gives you).
    2. Open the server you use for Table Runner (the inbound one is fine), choose API Tokens, and copy the Server API token.
    3. Paste it here with the From address and save. Then send yourself a test.
    4. Set the address in emails to the public Table Runner address, not one behind Vercel's login, or invite links will not open for staff.
