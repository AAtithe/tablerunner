Table Runner

OpenTable allocation and SevenRooms sync

Set up Table Runner

This install has no admin yet. The setup code is in the Vercel logs: open the tablerunner project in Vercel, choose Logs, and search for "setup code". You become the first admin; everyone else gets their own sign-in on the Users screen.

Sign in

Upgrading from shared passwords: until a named admin exists, the old admin password still works once.

Settings:

OpenTable emails in
Webhook address (set automatically when Postmark is connected)
Treat this address like a password. A new key stops the old address at once; a connected Postmark is updated automatically.
Alerts
Alerts always show here. With a webhook they also go to that channel.
SevenRooms
Floor plan and OpenTable allocation
Set "example" to false once this is the venue's real floor plan. The venue code cannot change.

Clients and sites

A client is the group (for example Open House). Each site is one venue under it (for example Broadcaster), with its own floor plan, SevenRooms, emails in and alerts.

Add a client
Then add its sites alongside, and give people access to the whole client on the Users screen.
Add a site
The code keys the site's bookings and cannot change later. A site can move to another client at any time. A new site starts in shadow mode on the example floor plan: open its Settings to connect Postmark and paste the real floor plan.
